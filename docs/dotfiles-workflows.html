Start & maintain

Update the machine

The everyday entry is the Herdr project picker. Package updates are separate commands in Nushell.

  1. Herdr · ⌘ BChoose an existing worktree or project
  2. Optional, rarelyupdater cleanPrune caches and unused resources
  3. Update packagesupdater startRun available package-manager updates

updater clean is not required before updater start. It can remove caches, unused versions and Docker images; use it only when you want that cleanup. On box, Linux Trash and user journal cleanup are included.

Change a managed dotfile

  1. Edit sourcechezmoi edit <file>
  2. Previewchezmoi apply --dry-run
  3. Installchezmoi apply

From Herdr, ⌘ ⇧ C opens an apply popup. Raycast also has “Chezmoi Apply”. Yazi offers C then p for the selected file.

Add or sync packages

  1. Choose ownerBrewfile / Bun install script / uv install script / mise config
  2. Edit declarationChange the source file
  3. Installchezmoi apply

Nushell blocks manual brew install and global bun add. Use dot_Brewfile.tmpl, run_onchange_02_install-bun.sh.tmpl, run_onchange_03_install-uv-tools.sh.tmpl or dot_config/mise/config.toml.tmpl.

Bring target edits back to source

  1. Re-addchezmoi syncRuns chezmoi re-add
  2. If diff remainschezmoi edit --apply <file>Resolve templates first
  3. Run againchezmoi syncCommits and pushes when clean

chezmoi sync pushes the chezmoi repository. Review changes before running it.

Set up a new machine

  1. PrerequisitesInstall chezmoi; on macOS install Homebrew and Xcode tools
  2. Bootstrapchezmoi init --apply git@github.com:tifandotme/dotfiles.git
  3. FinishUnlock age key, then open a new terminal

Applies macOS-only configuration on the main machine and host-specific configuration on the Ubuntu VPS box. SSH access is needed for external repositories.

Projects & terminals

Open a project or worktree

  1. Herdr · ⌘ BOpen worktree picker
  2. SelectExisting worktree → Herdr opens it; project → Herdr creates a worktree
  3. While browsingEnter open/create · Ctrl X close clean worktree · Esc cancel

Run open-project in a Herdr-managed Nushell pane for the same picker. It previews branch/PR details and refuses to close dirty worktrees.

Arrange Herdr

  • ⌘ T new tab · ⌘ W close pane
  • ⌘ N new workspace · ⌘ X close workspace
  • ⌘ [ / ⌘ ] previous / next tab
  • Alt H/J/K/L focus pane
  • Ctrl E then | / - split vertical / horizontal
  • Ctrl E then F zoom · B sidebar · L lazygit
  • ⌘ R rename tab · ⌘ ⇧ R rename workspace
  • Alt [ / Alt ] previous / next agent

Work in the shell

  • Ctrl T find file · Ctrl O find directory
  • Ctrl R search history · Ctrl H help
  • Ctrl G edit current command · Alt Enter newline
  • commands list custom commands
  • y open Yazi; exit to change shell directory

Navigate and manage files in Yazi

  • g C chezmoi source · g w work projects · g p personal projects
  • g r Git root · ! shell here
  • C a add · C t template · C e encrypt
  • C p apply · C r re-add · C f forget
  • ? help · T toggle max preview

Desktop

macOS only

Switch windows and spaces

  1. AeroSpace⌘ 1–6 switch workspace; ⌘ ⇧ 1–6 move window and follow
  2. ArrangeAlt Enter float/tile · Alt . tiles · Alt , accordion
  3. Move mode⌘ ⇧ ' then H/J/K/L move · Esc finish

0 misc, 1 personal, 2 work, 3 dev, 4 terminal, 5 notes, 6 auxiliary. ⌘ ` goes to misc. ⌘ ⇧ ; then Esc reloads AeroSpace, SketchyBar and Borders.

Change colors and appearance

  1. Wallpaper colorRaycast “Apply Theme” [optional hex] → palette + app reload
  2. UndoRaycast “Undo Wallpaper Theme”
  3. Light / darkRaycast “Toggle Appearance” → chezmoi source + apply

Theme palette feeds Herdr, SketchyBar and Borders. Appearance switch updates Git delta, Glow and Herdr as well as macOS.

Use desktop utilities

  • Raycast “Toggle Caffeinate” keeps the Mac awake
  • Raycast “Toggle Helium Zoom” restarts Helium
  • SketchyBar shows workspaces, Herdr state, Slack, Linear, network, battery and usage
  • SketchyBar Wi-Fi item and Slack item have click actions

Development

Work with Git and remotes

  1. Locallzg opens lazygit; compare picks two files to diff
  2. Work repo on weekendEligible pushes and PR creates enter work-remote queue
  3. Weekdaywork-remote list → work-remote run → type RUN

The weekend guard applies to work repositories. Queue execution is disabled on Saturday and Sunday unless explicitly overridden; tasks are revalidated before remote changes.

Launch coding agents

  1. From project directorypi or claude
  2. AutomaticPi selects work/personal MCP config by path; Claude syncs MCP policy
  3. In HerdrPane/tab gets a temporary agent label

claudex routes Claude through the local proxy. nvimg opens Neovim at the Git root.

Containers and remote sessions

  • stop-all stops running Docker containers
  • stop-all --stop-colima also stops Colima
  • ssh, sshs, mosh label the Herdr tab/pane temporarily
  • lzd opens lazydocker with a temporary label

Small tools worth remembering

  • youtube-download URL → Downloads; --audio or --cwd changes output
  • open-book → pick and open a local PDF or EPUB
  • prep-excalidraw → shrink/convert images to WebP; removes originals after success
  • cert check DOMAIN → TLS validity and days remaining
  • git rebase-release → fetch upstream tags and rebase to latest release
  • gibo gibo-strip → generate .gitignore without attribution header
