Start & maintain

Update the machine

The everyday entry is the Herdr project picker. Package updates are separate mise tasks.

  1. Herdr · ⌘ BChoose an existing worktree or project
  2. Optional, rarelymise run updater:cleanPrune caches and unused resources
  3. Update packagesmise run updater:startRun available package-manager updates

mise run updater:clean is not required before updating. It can remove caches, unused versions and Docker images; use it only when you want that cleanup. On box, Linux Trash and user journal cleanup are included.

Change a managed dotfile

  1. Edit sourcechezmoi edit <file>
  2. Previewchezmoi apply --dry-run
  3. Installchezmoi apply

Yazi offers C then p for the selected file.

Add or sync packages

  1. Choose ownerHomebrew / Bun / uv / mise / standalone CLI installer
  2. Edit declarationChange the source file
  3. Installchezmoi apply

Shell wrappers block manual brew install and global bun add. Use dot_Brewfile.tmpl, run_onchange_02_install-bun.sh.tmpl, run_onchange_03_install-uv-tools.sh.tmpl, dot_config/mise/config.toml.tmpl, or run_after_05_install-cli-tools.sh.tmpl only when no package-manager install fits.

Bring target edits back to source

  1. Re-addchezmoi syncRuns chezmoi re-add
  2. If diff remainschezmoi edit --apply <file>Resolve templates first
  3. Run againchezmoi syncCommits and pushes when clean

chezmoi sync pushes the chezmoi repository. Review changes before running it.

Set up a new machine

  1. PrerequisitesInstall chezmoi; on macOS install Homebrew and Xcode tools
  2. Bootstrapchezmoi init --apply git@github.com:tifandotme/dotfiles.git
  3. FinishUnlock age key; on box, approve the sudo prompt if it needs to add Zsh to /etc/shells; open a new SSH session

Applies macOS-only configuration on the main machine and host-specific configuration on the Ubuntu VPS box. SSH access is needed for external repositories.

Projects & terminals

Open a project or worktree

  1. Herdr · ⌘ BOpen worktree picker
  2. SelectExisting worktree → Herdr opens it; project → enter a branch name and Herdr creates the worktree
  3. Path~/projects/{work|personal}/<repo>-<branch>Branch slashes become hyphens
  4. While browsingEnter open/create · Ctrl X close a clean, merged worktree with no ignored files · Esc cancel

Run mise run project:open in a Herdr-managed pane for the same picker. It previews branch/PR details. Cleanup refuses dirty or ignored files and branches that are not confirmed merged into the default branch. Run mise run project:prune to review and prune missing Git worktree registrations. It can also close stale Herdr workspaces for missing checkouts, which stops their agents; workspaces with working or blocked agents are skipped.

Development

Work with Git and remotes

  1. Locallzg opens lazygit; mise run files:compare picks two files to diff
  2. Remotegit push and gh pr create run normally, any day

mise run commit:generate generates a message and commits staged changes. Claude uses the personal OAuth token through claude:personal; --agent pi keeps Pi authentication unchanged. On macOS, press C in lazygit's files panel to choose either generator.

Launch coding agents

  1. From project directorypi or claude
  2. AutomaticClaude MCP setup provisions fff, Tolaria, and Penpot on both profiles and prunes other user-scope servers. Remote MCPs (Linear, Context7, Tavily) are claude.ai connectors managed in the UI; the Hadl profile denies unwanted connectors through deniedMcpServers. Amp remote MCPs stay account-managed.
  3. AutostartBox starts box-amp-personal and box-amp-work at boot; macOS starts macbook-amp-personal and macbook-amp-work at login. All sessions run in tmux.Attach with tmux attach -t SESSION. Start a Box Claude repo with mise run agents:start:claude OWNER/REPO; it clones into the owner's directory (hadl-labs in ~/projects/work, tifandotme in ~/projects/personal) when missing, and tifandotme/dotfiles uses the chezmoi source. Start Amp manually with mise run agents:start:amp personal|work. Stop with mise run agents:stop OWNER/REPO or mise run agents:stop amp:personal|amp:work. Box uses runner box for both profiles; macOS uses macbook for both profiles.
  4. In HerdrPane/tab gets a temporary agent label

Claude's statusline starts with blue PERSONAL or orange HADL. Personal OAuth keeps the PERSONAL label even with the Hadl profile. nvimg opens Neovim at the Git root.

Personal accounts are the default. Under ~/projects/work, mise selects the Hadl Amp key, claude-hadl profile, and hadl gcloud configuration at launch. Leaving the directory restores personal selection for new processes; running agents keep their account. Shell wrappers and Box launch tasks use mise explicitly. GUI apps do not inherit directory-scoped selection.

Claude profiles share managed settings, coding rules, hooks, keybindings, and RTK, but keep logins, history, trust, agents, and skills separate. Each global CLAUDE.md contains only its own Linear workspace and gcloud account. Hadl production safeguards live in ~/projects/work/AGENTS.md, imported by the adjacent CLAUDE.md. After applying, sign in once with mise exec -C ~/projects/work -- claude auth login --claudeai and confirm with mise exec -C ~/projects/work -- claude auth status. Run mise run claude:extra-usage from the intended project to report only that profile's usage.

Account labels are bold. With personal OAuth in the Hadl profile, the statusline shows orange PERSONAL: the label identifies the account, and the color identifies the profile.

To continue with personal Claude OAuth on macOS or Box, exit Claude and run mise run claude:personal -- --resume SESSION_ID from the same worktree. This keeps the selected profile and saved login. Generate a personal token with claude setup-token, then paste it into mise run claude:personal --store-token. Chezmoi encrypts it separately from ~/.secrets; only this launcher exports it. Sync and apply the encrypted file on Box. Check /status and account-provided MCP access before continuing. Setup and verification.

On box, ~/projects/ is served directly at https://box.javanese-pound.ts.net:8443/. Agents link to live files without copying them. Connect the viewing device to Tailscale. Links stop working when files or worktrees are deleted.

Ask an agent to share a selected file publicly with sharing-public-files. Funnel uses port 10000, while port 443 serves app domains and port 8443 stays private. Shares can expire or remain public until stopped.

Authenticated browsing on box

  1. Load the skillauthenticating-browsers scans available site seeds
  2. Start a task sessionImport the selected site's seed with --state and --restore
  3. Continue laterReuse the session with --restore; omit --state

Refresh expired login state from Helium for Agents on the Mac. Chezmoi stores seeds encrypted; each task keeps its updated browser state separately. New sites need no skill edit. The box-only AppArmor policy keeps Chrome's sandbox enabled.

Global workflow tasks

  • mise tasks ls lists tasks from any directory; Tab completes task names and declared choices.
  • mise run agents:status shows local agent tmux sessions; start Amp with agents:start:amp personal|work, stop with agents:stop amp:personal|amp:work, and start Box Claude with agents:start:claude OWNER/REPO.
  • mise run db:list lists connection metadata; mise run db:tunnel core_db_staging opens one tunnel; without an argument it opens every missing one.
  • mise run db:psql core_db_staging -- -Atc 'select 1' uses a fresh IAM token.
  • On Mac, mise run helium:run starts Helium for Agents. mise run helium:setup work creates the Work instance. mise run claude:setup builds the isolated Claude Hadl desktop app (HADL sign-in, claude-hadl config).
  • Use mise run TASK --help for task arguments. Project tasks can override global names.
