# Issue tracker: Linear

Issues and specs for this repository live in the Citra workspace, in the Citra (TIF) team. Use Linear MCP for issue operations.

## Conventions

- Search for related issues before creating a new one.
- Create issues in the Citra (TIF) team and set their status to Backlog unless the user specifies another status.
- Apply the `dotfiles` label to identify issues for this repository.
- Do not assign a project unless the user specifies one.
- Use the triage labels in `triage-labels.md`.
- When publishing an agreed spec, apply the `ready-for-agent` label.

## Skill workflows

- When a skill says to publish to the issue tracker, create a Linear issue in the Citra (TIF) team.
- When a skill says to fetch a relevant ticket, read the Linear issue and its comments.
