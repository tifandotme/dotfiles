# Domain Docs

## Before exploring

- Read this repository's root and applicable nested `AGENTS.md` files.
- Read applicable ADRs if they exist.
- This repository does not use `CONTEXT.md`; do not require or create one as routine setup.

## Domain guidance

Use existing repository instructions, documentation, and code as the source of truth. Add a glossary or ADR only when a task needs durable domain terms or a recorded decision.

## ADR conflicts

If a change conflicts with an existing ADR, state the conflict rather than silently overriding the decision.
